# Milestone 2: Booking, Wallet and Payments — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Customers sign in with Google, top up a prepaid wallet through Razorpay (or cash at the counter), book specific PCs on a neon seat map, cancel or add time; staff see bookings and "Time up" alerts on the existing dashboard.

**Architecture:** One new Django app, `booking`, next to `status/` in the same project and PostgreSQL database. Pure booking rules live in `booking/rules.py`; everything that touches the database (booking, cancelling, extending, crediting) lives in `booking/services.py`; views stay thin. PostgreSQL's exclusion constraint makes double-booking impossible; an append-only `WalletEntry` ledger holds every rupee movement. Pages are Django templates with plain JavaScript, Motion (vendored) for animation and the browser's View Transitions for page changes.

**Tech Stack:** Python 3.12, Django 5.2 LTS, PostgreSQL 17 (`btree_gist`), psycopg 3, django-allauth (Google only), Razorpay Orders API + Checkout via Python stdlib, Motion (vanilla JS build), Docker Compose.

**Spec:** `docs/superpowers/specs/2026-10-11-m2-booking-design.md`

## Global Constraints

- Python 3.12, Django 5.2 LTS, PostgreSQL 17, the existing Docker Compose stack in `deploy/`.
- Only one new Python dependency: `django-allauth[socialaccount]`. Razorpay is called with `urllib`, `hmac`, `hashlib`. No npm, no build step.
- Money in the ledger and in Razorpay orders is integer **paise**. Prices staff type are whole **rupees** (`hourly_rate_rupees`, `Offer.pay_rupees`, `Offer.bonus_rupees`).
- Wallet entries are append-only: never edited or deleted, in code or admin.
- Only the server clock is used. Café local time comes from `TIME_ZONE` (`Asia/Kolkata`).
- Amounts, prices and bonuses are computed on the server only; nothing the browser sends is trusted.
- Customers sign in with Google only; local password sign-up is closed. Dashboard and admin require `is_staff`.
- Colour meanings: yellow `#FCEE0A` = your selection / primary action; cyan `#00E5FF` = free; magenta `#FF2A6D` = taken, errors, time up. Every state also has a text label.
- Copy: sentence case, plain verbs, buttons say exactly what happens ("Book 2 PCs for ₹300"). Errors say what went wrong and what to do.
- All animation is off under `prefers-reduced-motion: reduce`.
- Secrets only in `deploy/.env`; never in git.

## Review Focus

1. **A customer double-taps "Book"** (two POSTs for the same seats). They must end up with one booking and one charge, and see a clear message, not an error page. Pinned by Task 8: `test_double_submit_books_once`.
2. **Razorpay's browser callback and its webhook both arrive** for the same payment, in either order. The wallet must be credited exactly once, bonus included. Pinned by Task 7: `test_webhook_then_callback_credits_once`, and Task 5: `test_credit_topup_twice_credits_once`.
3. **The balance is exactly the price.** Booking must succeed and leave ₹0, not be refused. Pinned by Task 5: `test_exact_balance_is_enough`.
4. **Staff change the hourly rate after someone booked.** Cancelling must refund what the customer actually paid, not the new price. Pinned by Task 5: `test_refund_uses_price_paid_not_new_rate`.
5. **A late-night café (closes after midnight).** A 23:30–01:00 booking is valid, start times after midnight are listed under the evening's day, and at 00:30 "Today" means the evening that started yesterday. Pinned by Task 4: `test_booking_across_midnight`, `test_start_times_run_past_midnight`, `test_booking_days_after_midnight_start_with_yesterday`.

```python
from datetime import datetime, time, timedelta

from django.contrib.auth.models import User
from django.utils import timezone

from booking.models import Customer, WalletEntry
from status.models import PC, CafeSettings


def make_customer(name="asha", rupees=0, phone="9876543210"):
    user = User.objects.create_user(name, email=f"{name}@example.com", first_name=name.title())
    customer = Customer.objects.create(user=user, phone=phone)
    if rupees:
        WalletEntry.objects.create(customer=customer, amount_paise=rupees * 100, kind=WalletEntry.TOPUP_CASH)
    return customer


def make_pcs(n):
    return [PC.objects.create(hostname=f"PC{i:02}", label=f"PC{i:02}") for i in range(1, n + 1)]


def tomorrow_at(hour, minute=0):
    """Tomorrow at hour:minute café time (aware)."""
    day = timezone.localdate() + timedelta(days=1)
    return timezone.make_aware(datetime.combine(day, time(hour, minute)))


def open_24h():
    """Make the café open around the clock, so tests that book "now" pass at any hour."""
    cafe = CafeSettings.load()
    cafe.opens_at = cafe.closes_at = time(0)
    cafe.save()
    return cafe
```

```python
from django.conf import settings
from django.contrib.postgres.constraints import ExclusionConstraint
from django.contrib.postgres.fields import DateTimeRangeField, RangeOperators
from django.core.validators import RegexValidator
from django.db import models
from django.db.models import Q
from django.utils import timezone


class Customer(models.Model):
    """A website customer. Created on first Google sign-in; name and email come from Google."""

    user = models.OneToOneField(settings.AUTH_USER_MODEL, on_delete=models.PROTECT, related_name="customer")
    phone = models.CharField(
        max_length=10, blank=True,
        validators=[RegexValidator(r"^[6-9]\d{9}$", "Enter a 10-digit Indian mobile number.")],
    )
    created_at = models.DateTimeField(auto_now_add=True)

    def __str__(self):
        return self.user.get_full_name() or self.user.email or self.user.username

    @property
    def first_name(self):
        return self.user.first_name or str(self)


class Booking(models.Model):
    """One PC for one time range. PCs booked together share a `group`."""

    customer = models.ForeignKey(Customer, on_delete=models.PROTECT, related_name="bookings")
    pc = models.ForeignKey("status.PC", on_delete=models.PROTECT, related_name="bookings")
    period = DateTimeRangeField()  # [start, end)
    group = models.UUIDField(db_index=True)
    created_at = models.DateTimeField(auto_now_add=True)
    cancelled_at = models.DateTimeField(null=True, blank=True)
    cleared_at = models.DateTimeField(null=True, blank=True)
    cleared_by = models.ForeignKey(
        settings.AUTH_USER_MODEL, null=True, blank=True, on_delete=models.SET_NULL, related_name="+"
    )

    class Meta:
        constraints = [
            # The database itself refuses two live bookings on one PC at overlapping times.
            ExclusionConstraint(
                name="no_double_booking",
                expressions=[("pc", RangeOperators.EQUAL), ("period", RangeOperators.OVERLAPS)],
                condition=Q(cancelled_at__isnull=True),
            ),
        ]

    def __str__(self):
        return f"{self.pc} for {self.customer}"

    @property
    def start(self):
        return self.period.lower

    @property
    def end(self):
        return self.period.upper


class WalletEntry(models.Model):
    """One rupee movement. Append-only: the balance is the sum of a customer's entries."""

    TOPUP_ONLINE, TOPUP_CASH, BONUS = "topup_online", "topup_cash", "bonus"
    BOOKING, EXTENSION, REFUND, CORRECTION = "booking", "extension", "refund", "correction"
    KINDS = [
        (TOPUP_ONLINE, "Online top-up"), (TOPUP_CASH, "Cash top-up"), (BONUS, "Offer bonus"),
        (BOOKING, "Booking"), (EXTENSION, "Added time"), (REFUND, "Cancellation refund"),
        (CORRECTION, "Correction"),
    ]

    customer = models.ForeignKey(Customer, on_delete=models.PROTECT, related_name="wallet_entries")
    amount_paise = models.BigIntegerField()
    kind = models.CharField(max_length=16, choices=KINDS)
    booking = models.ForeignKey(Booking, null=True, blank=True, on_delete=models.PROTECT, related_name="wallet_entries")
    razorpay_payment_id = models.CharField(max_length=64, null=True, blank=True, unique=True)
```

`server/booking/rules.py`:
```python
"""Booking rules (m2 spec §5). Pure functions, no Django: easy to test.

Datetimes are timezone-aware and already in café local time. `s` is anything with the CafeSettings
booking fields: booking_step_min, min_booking_min, advance_days, opens_at, closes_at.
"""
from datetime import datetime, timedelta

MAX_LENGTH_MIN = 12 * 60  # longest length the booking form offers


def price_paise(rate_rupees, minutes):
    """Hourly rate × length, rounded half-up to the paise."""
    return (rate_rupees * 100 * minutes * 2 + 60) // 120


def _period(day, opens, closes, tz):
    """The opening period that begins on `day`. Closing at or before opening means the next day."""
    close_day = day if closes > opens else day + timedelta(days=1)
    return datetime.combine(day, opens, tz), datetime.combine(close_day, closes, tz)


def opening_period(at, opens, closes):
    """(open, close) of the opening period containing `at`, or None if the café is closed then."""
    if opens == closes:  # open around the clock: no closing time to respect
        return at, datetime.max.replace(tzinfo=at.tzinfo)
    for day in (at.date() - timedelta(days=1), at.date()):
        open_dt, close_dt = _period(day, opens, closes, at.tzinfo)
        if open_dt <= at < close_dt:
            return open_dt, close_dt
    return None


def check_times(start, minutes, now, s, start_now=False):
    """Why [start, start + minutes) can't be booked, in words for the customer; None if it can."""
    step = s.booking_step_min
    if minutes < s.min_booking_min or minutes % step:
        return f"Pick a length of at least {s.min_booking_min} minutes, in steps of {step} minutes."
    if not start_now:
        if start.minute % step or start.second or start.microsecond:
            return f"Start times are every {step} minutes."
        if start < now:
            return "That start time has passed. Pick a later one."
    if start - now > timedelta(days=s.advance_days):
        return f"You can book up to {s.advance_days} days ahead."
    period = opening_period(start, s.opens_at, s.closes_at)
    if period is None:
        return "The café is closed at that time."
    if start + timedelta(minutes=minutes) > period[1]:
        return f"The café closes at {period[1]:%H:%M}. Pick a shorter length."
    return None


def cancel_deadline(start, cutoff_min):
    return start - timedelta(minutes=cutoff_min)


def can_cancel(start, now, cutoff_min):
    return now <= cancel_deadline(start, cutoff_min)


def booking_days(now, s):
    """Days to pick from: the opening day in progress (or today), then the next `advance_days`."""
    current = opening_period(now, s.opens_at, s.closes_at)
    first = current[0].date() if current else now.date()
    return [first + timedelta(days=i) for i in range(s.advance_days + 1)]


def start_times(day, now, s):
    """Future start times, every step, in the opening period that begins on `day`."""
    open_dt, close_dt = _period(day, s.opens_at, s.closes_at, now.tzinfo)
    step = timedelta(minutes=s.booking_step_min)
    latest = min(close_dt - timedelta(minutes=s.min_booking_min), now + timedelta(days=s.advance_days))
    times, t = [], open_dt
    while t <= latest:
        if t >= now:
            times.append(t)
        t += step
    return times


def lengths(s):
    return list(range(s.min_booking_min, MAX_LENGTH_MIN + 1, s.booking_step_min))
```

```python
from django.db import connection
from django.test import TransactionTestCase

from booking import services

from .helpers import make_customer, make_pcs, open_24h, tomorrow_at


class ConcurrencyTests(TransactionTestCase):
    """Two requests at the same instant, each on its own database connection."""

    def setUp(self):
        open_24h()
        self.pc1, self.pc2 = make_pcs(2)
        self.now, self.start = timezone.now(), tomorrow_at(12)

    def race(self, *calls):
        barrier, results = threading.Barrier(len(calls)), []

        def run(call):
            try:
                barrier.wait()
                call()
                results.append(True)
            except BookingError:
                results.append(False)
            finally:
                connection.close()

        threads = [threading.Thread(target=run, args=(call,)) for call in calls]
        for thread in threads:
            thread.start()
        for thread in threads:
            thread.join()
        self.assertEqual(len(results), len(calls), "a thread raised something other than BookingError")
        return results.count(True)

    def test_same_pc_same_time_only_one_wins(self):
        a, b = make_customer("asha", 500), make_customer("ravi", 500)
        wins = self.race(
            lambda: services.book(a, [self.pc1.id], self.start, 60, self.now),
            lambda: services.book(b, [self.pc1.id], self.start, 60, self.now),
        )
        self.assertEqual(wins, 1)
        self.assertEqual(Booking.objects.count(), 1)

    def test_one_wallet_cannot_be_spent_twice(self):
        a = make_customer("asha", 100)
        wins = self.race(
            lambda: services.book(a, [self.pc1.id], self.start, 60, self.now),
            lambda: services.book(a, [self.pc2.id], self.start, 60, self.now),
        )
        self.assertEqual(wins, 1)
        self.assertEqual(services.balance_paise(a), 0)
```

```python
"""Booking and wallet operations (m2 spec §5–6). Every rupee movement is a WalletEntry row."""
from datetime import timedelta
from uuid import uuid4

from django.db import IntegrityError, transaction
from django.db.backends.postgresql.psycopg_any import DateTimeTZRange
from django.db.models import Sum
from django.utils import timezone

from status.models import PC, CafeSettings
from status.state import IN_USE, compute_state

from . import rules
from .models import Booking, Customer, Offer, TopUpOrder, WalletEntry

TOPUP_MIN_RUPEES, TOPUP_MAX_RUPEES = 100, 10_000
TIME_UP_HIDE_AFTER = timedelta(hours=6)


class BookingError(Exception):
    """A request was refused. str(error) is shown to the customer as-is."""


def balance_paise(customer):
    return customer.wallet_entries.aggregate(total=Sum("amount_paise"))["total"] or 0


def paid_paise(booking):
    """Everything paid for this booking: the booking plus any added time."""
    kinds = [WalletEntry.BOOKING, WalletEntry.EXTENSION]
    return -(booking.wallet_entries.filter(kind__in=kinds).aggregate(total=Sum("amount_paise"))["total"] or 0)


def _live_bookings():
    return Booking.objects.filter(cancelled_at__isnull=True)


def _in_use_pc_ids(now, cafe):
    return {
        pc.id for pc in PC.objects.filter(is_active=True)
        if compute_state(pc.last(), now, cafe.idle_threshold_s, cafe.offline_timeout_s)[0] == IN_USE
    }


def seat_map(start, end, now, cafe, start_now=False):
    """Every active PC with whether it's free for [start, end).

    free_until: when a PC is free at `start` but has a later booking, that booking's start.
    For "Start now", a PC that is In Use with no booking (someone sitting there) is taken.
    """
    taken = set(_live_bookings().filter(period__overlap=DateTimeTZRange(start, end)).values_list("pc_id", flat=True))
    in_use = _in_use_pc_ids(now, cafe) if start_now else set()
    first_after = {}
    for pc_id, period in _live_bookings().filter(period__endswith__gt=start).order_by("period").values_list("pc_id", "period"):
        first_after.setdefault(pc_id, period.lower)
    return [
        {
            "pc": pc,
            "free": pc.id not in taken | in_use,
            "free_until": None if pc.id in in_use or first_after.get(pc.id, start) <= start else first_after[pc.id],
        }
        for pc in PC.objects.filter(is_active=True)
    ]


def book(customer, pc_ids, start, minutes, now, start_now=False):
    """Book the PCs for `minutes` from `start` (or from now) and pay from the wallet."""
    cafe = CafeSettings.load()
    if start_now:
        start = now.replace(second=0, microsecond=0)
    error = rules.check_times(timezone.localtime(start), minutes, timezone.localtime(now), cafe, start_now)
    if error:
        raise BookingError(error)
    wanted = set(pc_ids)
    pcs = list(PC.objects.filter(id__in=wanted, is_active=True))
    if not pcs or len(pcs) != len(wanted):
        raise BookingError("Pick at least one available PC.")
    end = start + timedelta(minutes=minutes)
    busy = [seat["pc"] for seat in seat_map(start, end, now, cafe, start_now) if seat["pc"].id in wanted and not seat["free"]]
    if busy:
        raise BookingError(f"{busy[0]} isn't free for that time. Pick another seat.")
    price = rules.price_paise(cafe.hourly_rate_rupees, minutes)
    group, bookings = uuid4(), []
    try:
        with transaction.atomic():
            Customer.objects.select_for_update().get(pk=customer.pk)  # one spend at a time per wallet
            if balance_paise(customer) < price * len(pcs):
                raise BookingError("Not enough balance. Top up to book.")
            for pc in pcs:
                booking = Booking.objects.create(customer=customer, pc=pc, group=group, period=DateTimeTZRange(start, end))
                WalletEntry.objects.create(customer=customer, amount_paise=-price, kind=WalletEntry.BOOKING, booking=booking, at=now)
                bookings.append(booking)
    except IntegrityError:  # the no-overlap constraint: someone booked a seat a moment ago
        raise BookingError("One of those PCs was just booked by someone else. Pick another seat.") from None
    return bookings


def cancel(booking, now, by_staff=False):
    """Cancel one booked PC and refund everything paid for it to the wallet. Returns the refund."""
    cafe = CafeSettings.load()
    with transaction.atomic():
        booking = Booking.objects.select_for_update().get(pk=booking.pk)
        if booking.cancelled_at:
            raise BookingError("This booking is already cancelled.")
        if not by_staff and not rules.can_cancel(booking.start, now, cafe.cancel_cutoff_min):
            deadline = timezone.localtime(rules.cancel_deadline(booking.start, cafe.cancel_cutoff_min))
            raise BookingError(f"Cancellation closed at {deadline:%H:%M on %d %b}.")
        refund = paid_paise(booking)
        booking.cancelled_at = now
        booking.save(update_fields=["cancelled_at"])
        WalletEntry.objects.create(customer=booking.customer, amount_paise=refund, kind=WalletEntry.REFUND, booking=booking, at=now)
    return refund


def extend(booking, minutes, now):
    """Add time to a current or upcoming booking, paid from the wallet. Returns the price."""
    cafe = CafeSettings.load()
    if minutes <= 0 or minutes % cafe.booking_step_min:
        raise BookingError(f"Add time in steps of {cafe.booking_step_min} minutes.")
    price = rules.price_paise(cafe.hourly_rate_rupees, minutes)
    try:
        with transaction.atomic():
            Customer.objects.select_for_update().get(pk=booking.customer_id)
            booking = Booking.objects.select_for_update().get(pk=booking.pk)
            if booking.cancelled_at or booking.end <= now:
                raise BookingError("This booking has ended.")
            new_end = booking.end + timedelta(minutes=minutes)
            period = rules.opening_period(timezone.localtime(booking.start), cafe.opens_at, cafe.closes_at)
            if period is None or new_end > period[1]:
                raise BookingError("That goes past closing time. Add less time.")
            if balance_paise(booking.customer) < price:
                raise BookingError("Not enough balance. Top up to add time.")
            booking.period = DateTimeTZRange(booking.start, new_end)
            booking.save(update_fields=["period"])
            WalletEntry.objects.create(customer=booking.customer, amount_paise=-price, kind=WalletEntry.EXTENSION, booking=booking, at=now)
    except IntegrityError:
        raise BookingError(f"{booking.pc} is booked right after you, so time can't be added.") from None
    return price


def live_offers(now, cafe):
    """Active offers, each with `.hours`: what the top-up plus bonus buys at the current rate."""
    offers = list(Offer.live(now))
    for offer in offers:
        offer.hours = (offer.pay_rupees + offer.bonus_rupees) / cafe.hourly_rate_rupees
    return offers


def topup_terms(amount_rupees, offer, now):
    """(amount_paise, bonus_paise, offer) for a top-up. A typed amount equal to an offer gets its bonus."""
    if offer is None:
        if not TOPUP_MIN_RUPEES <= amount_rupees <= TOPUP_MAX_RUPEES:
            raise BookingError(f"Top up between ₹{TOPUP_MIN_RUPEES} and ₹{TOPUP_MAX_RUPEES:,}.")
        offer = Offer.live(now).filter(pay_rupees=amount_rupees).first()
        if offer is None:
            return amount_rupees * 100, 0, None
    elif not offer.is_valid(now):
        raise BookingError("That offer has ended. Pick another amount.")
    return offer.pay_rupees * 100, offer.bonus_rupees * 100, offer


def credit_topup(order, payment_id, now):
    """Credit a paid Razorpay order (and its bonus) once. False if it was already credited."""
    with transaction.atomic():
        order = TopUpOrder.objects.select_for_update().get(pk=order.pk)
        if order.paid_at:
            return False
        WalletEntry.objects.create(customer=order.customer, amount_paise=order.amount_paise,
                                   kind=WalletEntry.TOPUP_ONLINE, razorpay_payment_id=payment_id, at=now)
        if order.bonus_paise:
            WalletEntry.objects.create(customer=order.customer, amount_paise=order.bonus_paise,
                                       kind=WalletEntry.BONUS, note=order.offer.name if order.offer else "", at=now)
        order.paid_at = now
        order.save(update_fields=["paid_at"])
    return True


def time_up(now):
    """Ended bookings staff haven't marked Cleared. Hidden 6 hours after the end."""
    return (
        _live_bookings()
        .filter(cleared_at__isnull=True, period__endswith__lte=now, period__endswith__gt=now - TIME_UP_HIDE_AFTER)
        .select_related("customer__user", "pc")
        .order_by("period")
    )


def tile_bookings(now):
    """{pc_id: {"now": booking playing now, "next": next booking in the coming 12 hours}}."""
    tiles = {}
    upcoming = _live_bookings().filter(period__endswith__gt=now, period__startswith__lt=now + timedelta(hours=12))
    for booking in upcoming.select_related("customer__user").order_by("period"):
        slot = tiles.setdefault(booking.pc_id, {"now": None, "next": None})
        if booking.start <= now:
            slot["now"] = booking
        elif slot["next"] is None:
            slot["next"] = booking
    return tiles
```

```python
def customer_required(view):
    """Signed in, with a Customer row and a phone number on file. Sets request.customer."""

    @login_required
    @wraps(view)
    def wrapper(request, *args, **kwargs):
        customer, _ = Customer.objects.get_or_create(user=request.user)
        if not customer.phone:
```

```python
from django import template

register = template.Library()


@register.filter
def rupees(paise):
    """12500 → "₹125", 2475 → "₹24.75", -15000 → "−₹150"."""
    sign = "−" if paise < 0 else ""
    whole, fraction = divmod(abs(int(paise)), 100)
    # ponytail: western digit grouping (1,00,000 shows as 100,000); wallets stay far below a lakh.
    return f"{sign}₹{whole:,}" + (f".{fraction:02}" if fraction else "")


@register.filter
def duration(minutes):
    """90 → "1 hr 30 min", 120 → "2 hrs", 30 → "30 min"."""
    hours, mins = divmod(int(minutes), 60)
    parts = [f"{hours} hr" + ("s" if hours > 1 and not mins else "")] if hours else []
    return " ".join(parts + ([f"{mins} min"] if mins else []))
```

```js
// Shared helpers for the customer site. Motion (window.Motion) is optional and off under reduced motion.
const reducedMotion = matchMedia("(prefers-reduced-motion: reduce)").matches;
const motion = () => (!reducedMotion && window.Motion) || null;

// Paise → "₹1,250" or "₹24.75".
function rupees(paise) {
  return "₹" + (Math.round(paise) / 100).toLocaleString("en-IN", { maximumFractionDigits: 2 });
}

// Roll a number element to a new value.
function rollTo(el, value, format) {
  const from = Number(el.dataset.value || 0);
  el.dataset.value = value;
  const m = motion();
  if (!m || from === value) { el.textContent = format(value); return; }
  m.animate(from, value, { duration: 0.35, ease: "easeOut", onUpdate: (v) => { el.textContent = format(v); } });
}

// A quick spring on something the user just tapped.
function pop(el) {
  const m = motion();
  if (m) m.animate(el, { scale: [0.92, 1] }, { type: "spring", stiffness: 500, damping: 18 });
}
```

```python
import base64
import hashlib
import hmac
import io
import json
from unittest.mock import patch

from django.test import SimpleTestCase, override_settings

from booking import razorpay


@override_settings(RAZORPAY_KEY_ID="rzp_test_x", RAZORPAY_KEY_SECRET="secret", RAZORPAY_WEBHOOK_SECRET="hook")
class RazorpayTests(SimpleTestCase):
    @patch("booking.razorpay.urllib.request.urlopen")
    def test_create_order_posts_paise_with_basic_auth(self, urlopen):
        urlopen.return_value.__enter__.return_value = io.BytesIO(b'{"id": "order_42"}')
        self.assertEqual(razorpay.create_order(50000, "r1"), "order_42")
        request = urlopen.call_args.args[0]
        self.assertEqual(request.full_url, "https://api.razorpay.com/v1/orders")
        self.assertEqual(json.loads(request.data), {"amount": 50000, "currency": "INR", "receipt": "r1"})
        self.assertEqual(request.get_header("Authorization"), "Basic " + base64.b64encode(b"rzp_test_x:secret").decode())

    def test_payment_signature(self):
        good = hmac.new(b"secret", b"order_1|pay_1", hashlib.sha256).hexdigest()
        self.assertTrue(razorpay.payment_signature_ok("order_1", "pay_1", good))
        self.assertFalse(razorpay.payment_signature_ok("order_1", "pay_2", good))
```

```python
"""Razorpay with the standard library only: one API call and two signature checks (m2 spec §6)."""
import base64
import hashlib
import hmac
import json
import urllib.request

from django.conf import settings

ORDERS_URL = "https://api.razorpay.com/v1/orders"


def create_order(amount_paise, receipt):
    """Create an order for `amount_paise` and return its id. Raises OSError/ValueError/KeyError on failure."""
    credentials = f"{settings.RAZORPAY_KEY_ID}:{settings.RAZORPAY_KEY_SECRET}".encode()
    request = urllib.request.Request(
        ORDERS_URL,
        data=json.dumps({"amount": amount_paise, "currency": "INR", "receipt": receipt}).encode(),
        headers={"Authorization": "Basic " + base64.b64encode(credentials).decode(), "Content-Type": "application/json"},
    )
    with urllib.request.urlopen(request, timeout=10) as response:
        return json.load(response)["id"]


def _signed(secret, message, signature):
    if not secret:  # an empty secret would let anyone forge a signature
        return False
    expected = hmac.new(secret.encode(), message, hashlib.sha256).hexdigest()
    return hmac.compare_digest(expected, signature)


def payment_signature_ok(order_id, payment_id, signature):
    """Checkout's success callback: HMAC-SHA256 of "order_id|payment_id" with the key secret."""
    return _signed(settings.RAZORPAY_KEY_SECRET, f"{order_id}|{payment_id}".encode(), signature)


def webhook_signature_ok(body, signature):
    """Webhook: HMAC-SHA256 of the raw body with the webhook secret."""
    return _signed(settings.RAZORPAY_WEBHOOK_SECRET, body, signature)
```

```python
def _error(text, status=400):
    return JsonResponse({"error": text}, status=status)


@require_POST
@customer_required
def topup_order(request):
    now, offer = timezone.now(), None
    offer_id, amount = request.POST.get("offer", ""), request.POST.get("amount", "")
    if offer_id:
        offer = Offer.objects.filter(pk=offer_id).first() if offer_id.isdigit() else None
        if offer is None:
            return _error("That offer has ended. Pick another amount.")
    elif not amount.isdigit():
        return _error(f"Enter an amount between ₹{services.TOPUP_MIN_RUPEES} and ₹{services.TOPUP_MAX_RUPEES:,}.")
    try:
        amount_paise, bonus_paise, offer = services.topup_terms(int(amount or 0), offer, now)
    except services.BookingError as error:
        return _error(str(error))
    try:
        order_id = razorpay.create_order(amount_paise, receipt=f"c{request.customer.pk}-{int(now.timestamp())}")
    except (OSError, ValueError, KeyError):
        return _error("Payments aren't available right now. Try again in a minute.", status=502)
    TopUpOrder.objects.create(razorpay_order_id=order_id, customer=request.customer,
                              amount_paise=amount_paise, bonus_paise=bonus_paise, offer=offer)
    user = request.user
    return JsonResponse({
        "order_id": order_id, "amount": amount_paise, "key": settings.RAZORPAY_KEY_ID,
        "name": CafeSettings.load().cafe_name,
        "prefill": {"name": user.get_full_name(), "email": user.email, "contact": request.customer.phone},
    })


@require_POST
@customer_required
def topup_paid(request):
    """Razorpay Checkout's success callback, relayed by the wallet page."""
    order_id = request.POST.get("razorpay_order_id", "")
    payment_id = request.POST.get("razorpay_payment_id", "")
    order = TopUpOrder.objects.filter(razorpay_order_id=order_id, customer=request.customer).first()
    if order is None or not razorpay.payment_signature_ok(order_id, payment_id, request.POST.get("razorpay_signature", "")):
        return _error("We couldn't confirm that payment. If money left your account, it will appear here within a few minutes.")
    services.credit_topup(order, payment_id, timezone.now())
    messages.success(request, "Payment received. Your balance is updated.")
    return JsonResponse({"ok": True})


@csrf_exempt  # protected by the signature instead
@require_POST
def razorpay_webhook(request):
    if not razorpay.webhook_signature_ok(request.body, request.headers.get("X-Razorpay-Signature", "")):
        return _error("bad signature")
    try:
        event = json.loads(request.body)
        payment = event["payload"]["payment"]["entity"]
    except (ValueError, KeyError, TypeError):
        return JsonResponse({"ok": True})  # signed, but not a payment event: nothing to do
    if event.get("event") == "payment.captured":
        order = TopUpOrder.objects.filter(razorpay_order_id=payment.get("order_id")).first()
        if order is not None and payment.get("amount") == order.amount_paise:
            services.credit_topup(order, payment["id"], timezone.now())
    return JsonResponse({"ok": True})  # 200 so Razorpay doesn't retry
```

```python
    return next((option for option in options if key(option) == value), None)


@customer_required
def book(request):
    now, cafe = timezone.now(), CafeSettings.load()
    local_now = timezone.localtime(now)
    params = request.POST if request.method == "POST" else request.GET
    days = rules.booking_days(local_now, cafe)

    can_start_now = day == days[0] and rules.opening_period(local_now, cafe.opens_at, cafe.closes_at) is not None
    starts = rules.start_times(day, local_now, cafe)
    start_now = can_start_now and params.get("start", "now") == "now"
    start = local_now.replace(second=0, microsecond=0) if start_now else (
        _choice(params.get("start"), starts, lambda t: t.strftime("%H:%M"))
        or (None if request.method == "POST" else (starts[0] if starts else None))
    )
    lengths = rules.lengths(cafe)
    minutes = _choice(params.get("minutes"), lengths, str) or cafe.min_booking_min
    picked = [p for p in params.getlist("pc") if p.isdigit()]

    if request.method == "POST":
        if start is None:
            messages.error(request, "Pick a start time.")
        else:
            try:
                bookings = services.book(request.customer, [int(p) for p in picked], start, minutes, now, start_now)
            except services.BookingError as error:
                messages.error(request, str(error))
            else:
                return redirect("ticket", group=bookings[0].group)

    seats = services.seat_map(start, start + timedelta(minutes=minutes), now, cafe, start_now) if start else []
```

```python
class WalletEntryForm(forms.ModelForm):
    """Staff add only cash top-ups and corrections, typed in rupees."""

    kind = forms.ChoiceField(choices=[(WalletEntry.TOPUP_CASH, "Cash top-up"), (WalletEntry.CORRECTION, "Correction")])
    rupees = forms.DecimalField(
        max_digits=9, decimal_places=2,
        help_text="Cash top-up: the cash received. Correction: positive adds, negative removes.",
    )
    offer = forms.ModelChoiceField(
        queryset=Offer.objects.none(), required=False,
        help_text="Cash top-ups only. The amount must match the offer.",
    )

    class Meta:
        model = WalletEntry
        fields = ["customer", "kind", "rupees", "offer", "note"]

    def __init__(self, *args, **kwargs):
        super().__init__(*args, **kwargs)
        self.fields["offer"].queryset = Offer.live(timezone.now())

    def clean(self):
        data = super().clean()
        kind, amount, offer = data.get("kind"), data.get("rupees"), data.get("offer")
        if amount is None:
            return data
        if kind == WalletEntry.TOPUP_CASH:
            if amount <= 0:
                self.add_error("rupees", "Enter the cash received.")
            if offer and amount != offer.pay_rupees:
                self.add_error("offer", f"This offer needs exactly ₹{offer.pay_rupees}.")
        else:
            if amount == 0:
                self.add_error("rupees", "Enter an amount other than zero.")
            if offer:
                self.add_error("offer", "Offers apply to cash top-ups only.")
            if not data.get("note"):
                self.add_error("note", "Say why you're correcting the balance.")
        return data

class WalletEntryAdmin(admin.ModelAdmin):

    list_display = ["at", "customer", "kind", "amount", "booking", "staff", "note"]
    list_filter = ["kind"]
    search_fields = ["customer__user__email", "customer__user__first_name", "customer__phone", "razorpay_payment_id"]
    autocomplete_fields = ["customer"]

    @admin.display(description="Amount")
    def amount(self, obj):
        return rupees(obj.amount_paise)

    def get_fields(self, request, obj=None):
        if obj is not None:  # viewing an existing entry: show what was recorded
            return ["at", "customer", "kind", "amount_paise", "booking", "razorpay_payment_id", "staff", "note"]
        return super().get_fields(request, obj)

    def get_form(self, request, obj=None, **kwargs):
        if obj is not None:
            kwargs["form"] = forms.ModelForm
        return super().get_form(request, obj, **kwargs)

    def save_model(self, request, obj, form, change):
        data, now = form.cleaned_data, timezone.now()
        obj.amount_paise, obj.staff, obj.at = int(data["rupees"] * 100), request.user, now
        with transaction.atomic():
            super().save_model(request, obj, form, change)
            if data.get("offer"):
                WalletEntry.objects.create(customer=obj.customer, amount_paise=data["offer"].bonus_rupees * 100,
                                           kind=WalletEntry.BONUS, staff=request.user, at=now, note=data["offer"].name)

    def has_change_permission(self, request, obj=None):
        return False  # append-only ledger

    def has_delete_permission(self, request, obj=None):
        return False

class WhenFilter(admin.SimpleListFilter):
    title, parameter_name = "when", "when"

    def lookups(self, request, model_admin):
        return [("now", "Playing now"), ("today", "Today"), ("upcoming", "Upcoming"), ("past", "Past")]

    def queryset(self, request, queryset):
        now = timezone.now()
        day_start = timezone.make_aware(datetime.combine(timezone.localdate(), time.min))
        return {
            "now": lambda: queryset.filter(period__contains=now),
            "today": lambda: queryset.filter(period__overlap=DateTimeTZRange(day_start, day_start + timedelta(days=1))),
            "upcoming": lambda: queryset.filter(period__startswith__gt=now),
            "past": lambda: queryset.filter(period__endswith__lte=now),
        }.get(self.value(), lambda: queryset)()


@admin.register(Booking)
class BookingAdmin(admin.ModelAdmin):
    list_display = ["pc", "customer", "start", "end", "status"]
    list_filter = [WhenFilter, "pc"]
    search_fields = ["customer__user__email", "customer__user__first_name", "customer__phone", "pc__label", "pc__hostname"]
    readonly_fields = ["customer", "pc", "period", "group", "created_at", "cancelled_at", "cleared_at", "cleared_by"]
    actions = ["cancel_and_refund"]

    @admin.display(description="Start", ordering="period")
    def start(self, obj):
        return timezone.localtime(obj.start).strftime("%d %b %H:%M")

    @admin.display(description="End")
    def end(self, obj):
        return timezone.localtime(obj.end).strftime("%d %b %H:%M")

    @admin.display(description="Status")
    def status(self, obj):
        if obj.cancelled_at:
            return "Cancelled"
        return "Cleared" if obj.cleared_at else "Booked"

    @admin.action(description="Cancel and refund to wallet")
    def cancel_and_refund(self, request, queryset):
        now, done = timezone.now(), 0
        for booking in queryset:
            try:
                services.cancel(booking, now, by_staff=True)
                done += 1
            except services.BookingError as error:
                self.message_user(request, f"{booking.pc}: {error}", messages.WARNING)
        self.message_user(request, f"Cancelled and refunded {done} booking(s).")

    def has_add_permission(self, request):
        return False

    def has_change_permission(self, request, obj=None):
        return False

    def has_delete_permission(self, request, obj=None):
        return False
```
